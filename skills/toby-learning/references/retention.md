# Volume, recall, and language

The one-decision loop gets two cases wrong, which are many items the learner must remember and language use. The method from `SKILL.md` still applies, meaning predict before reveal, respond to the answer, climb the ladder, and close with retrieval. Here the method covers many small items on a schedule, or covers production.

## Spot the mode

- Retention — the learner names a count ("these 40 words"), hands you a list, table, or paradigm, or says "drill, memorize, quiz me, review." Success is recalling them later, after the session.
- Production (language) — the learner wants to say, write, or speak the target language, or hands you target-language text.

## The retrieval loop (retention)

1. Establish fast. Keep the first exposure of an item short, with the item and one anchor (a meaning, an image, a cognate, an etymology hook), and then move on. Deep-teach only the few items that everyone gets wrong: false friends, irregulars, the step people reverse.
2. Retrieve, don't re-show. After a few items, cover the answer and make the learner produce an earlier one from memory.
3. Expanding gaps. A freshly missed item comes back soon, after two or three others, and a solid one comes back later, after six to ten. Track each item's next look as a rough count of items ahead, so the gap scales with the session.
4. Interleave. Cycle the set so each item is retrieved cold after a gap. Drilling one item smooth before moving on feels like learning and predicts forgetting.
5. Grade and reschedule. A right answer from memory pushes the item far back, and a hesitant answer pushes it a medium distance. A missed item comes back soon and drops a rung on the ladder.
6. Keep difficulty in the band where the learner is mostly right, with effort. If it is too hard, shorten the gap, drop a rung, give a first-letter or category hint, or shrink the active set. If it is too easy, use longer gaps, climb to production, widen the set, or add an easily confused item. Start a beginner with five to seven items and add more as they learn them.

## The ladder, mapped

- Vocabulary: recognize (see the word, give the meaning), then cued recall (prompt in the other language, produce the word), then free production (use it in a sentence you build). Push toward producing the target word, because recognizing it only feels like knowing.
- Grammar: spot the form in input, then fill a frame with the form blanked, then produce a sentence that needs it.
- Facts (anatomy, terminology, pathways): recognize, then cloze the term the learner must produce, then free recall the set in order.

## Language errors

Choose the response from the goal and the error:

- Fluency turn, non-blocking error — leave the error uncorrected and recast it, which means you reply naturally with the correct form and do not flag the error. Learner: "Ayer yo voy al cine." You: "Ah, ¿fuiste al cine ayer? ¿Qué viste?" The past tense is modeled in a real reply and the conversation keeps going.
- Accuracy turn, or an error on the exact target — elicit self-repair: "Something's off in the tense — try again," then have them state the rule. This move is the language version of "don't hand the fix."
- An error they can't yet fix — supply it briefly and move on. Don't make a beginner search for a form they have never seen.
- Don't error-hunt. Output is how acquisition happens, and over-correction stops it. Correct the targeted pattern or the one that blocks meaning, and leave the rest uncorrected in a fluency turn.
- Beginner who can't produce yet — lead with input they can follow, and ask them to show they followed (point, choose, answer) before pushing production.

When you switch from leaving errors uncorrected to a tightening pass, say so in one line. Otherwise the learner can't tell why errors are suddenly flagged.

## Cards and quizzes

Offer cards and quizzes, because the owner wants them. Make cards from items the learner missed this session, at a pause or the close, so each card is anchored to a real memory. Each card has to meet this bar:

- Put one fact on each card. Split a two-part answer.
- Productive recall. Make them produce the term, and avoid multiple choice by default, which trains "I've seen this" and inflates confidence.
- Cloze the word the learner must produce. "Glycolysis converts glucose to two ___ (pyruvate)" works, because blanking "two" tests nothing.
- Put no give-aways in the prompt, such as a shared root, a length cue, or a grammar tell.
- Add context when context is the skill, so grammar and collocation cards get a sentence frame that shows the usage.

## Across sessions

You have no memory between sessions, so the file is the memory. Say so plainly when you offer the review file. For each item, the review file holds the prompt side, the answer side, the hard direction (usually production), a last-result tag, and a next-due marker. Up top, it holds what to review first, what is shaky, and what is retired.

In the next session, read the file and quiz the due and shaky items cold before any new material. Then update the tags and markers and hand the file back. Keep it human-readable so the learner rereads it, and offer an Anki-importable export if they ask.
