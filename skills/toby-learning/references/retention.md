# Volume, recall, and language

This file adapts `toby-learning` for memorizing large sets (vocabulary, terminology, paradigms) and practicing language production.

## Retrieval loop

1. **Introduce items briefly.** Show each new item with one memory anchor (meaning, cognate, or etymology) and move on. Explain in depth only items learners regularly confuse (false friends, irregular forms), and start beginners with five to seven active items.
2. **Test cold retrieval.** Hide the answer and have the learner produce earlier items from memory after a gap, and don't drill one item back-to-back.
3. **Space by accuracy.** Bring a missed item back after two or three items at a lower rung, a hesitant item after four or five, and a clean recall after six to ten.
4. **Adjust difficulty to keep effortful success.** Shorten the gap, drop a rung, or give a category cue when the learner stalls. Lengthen the gap, require full-sentence production, or mix in look-alike items when recall is effortless.

## Progression ladder

- **Vocabulary:** recognition (see target word, give meaning) → cued recall (see meaning, produce target word) → sentence production.
- **Grammar:** spot the form in input → fill a blanked frame → write a new sentence that requires the form.
- **Facts and pathways:** recognize → fill the blanked key term → recall the full sequence in order.

## Language production errors

Match error correction to the current exercise:

- **Fluency conversation (meaning is clear):** use a conversational recast that models the correct form naturally without stopping the exchange (`Learner: "Ayer yo voy al cine."` → `You: "Ah, ¿fuiste al cine ayer? ¿Qué viste?"`).
- **Accuracy practice on the target form:** prompt the learner to spot and fix the form ("Check the verb tense and try that line again"), then state the rule.
- **Unseen form:** supply the form briefly and keep moving. State in one line whenever you switch between fluency and accuracy modes.

## Flashcards

Offer flashcards built from the items the learner missed during the session:

- Put one fact per card, require producing the target term, and avoid multiple-choice prompts.
- Blank the substantive word (`"Glycolysis converts glucose to two ___ (pyruvate)"`), without root or length giveaways in the prompt.
- Include a short sentence frame on grammar and collocation cards so the context requires the target form.

## Multi-session review file

Because chat sessions don't persist memory automatically, offer a human-readable review file (or Anki export) recording each item's prompt, answer, production direction, last result, and next-due marker. At the start of the next session, read that file and quiz due and shaky items cold before introducing new material.
