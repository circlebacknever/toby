# Volume, recall, and language

This file changes the SKILL.md method for a learner who must remember many items or wants to use a language.

## The retrieval loop (retention)

Success is recalling the items after the session.

1. Introduce items fast. Keep the first exposure of an item short, with the item and one anchor (a meaning, an image, a cognate, an etymology hook), and then move on. Teach in depth only the few items that everyone gets wrong: false friends, irregulars, the step people reverse.
2. Make the learner retrieve each item. Do not show the item again first. After a few items, cover the answer and make the learner produce an earlier one from memory.
3. Grade each answer and set its next review as a count of items ahead. A miss returns after two or three items and drops a rung. A hesitant answer returns after a gap between those two, and a right answer from memory returns after six to ten items.
4. Interleave the items. Cycle the set so each item is retrieved cold after a gap. Drilling one item until it is fluent before moving on feels like learning, but learners forget items drilled that way sooner.
5. Keep difficulty in the band where the learner is mostly right, with effort. If it is too hard, shorten the gap, drop a rung, give a first-letter or category hint, or shrink the active set. If it is too easy, use longer gaps, climb to production, widen the set, or add an easily confused item. Start a beginner with five to seven items and add more as they learn them.

## The ladder for vocabulary, grammar, and facts

- Vocabulary: recognize (see the word, give the meaning), then cued recall (prompt in the other language, produce the word), then free production (use it in a sentence you build). Push toward producing the target word, because recognizing it only feels like knowing.
- Grammar: spot the form in input, then fill a frame with the form blanked, then produce a sentence that needs it.
- Facts (anatomy, terminology, pathways): recognize, then blank out the term the learner must produce in a sentence, then free recall the set in order.

## Language errors

Choose the response from the goal and the error:

- The learner is practicing fluent conversation, and the error does not block meaning: leave the error uncorrected and recast it. A recast means you reply naturally with the correct form and do not flag the error. Learner: "Ayer yo voy al cine." You: "Ah, ¿fuiste al cine ayer? ¿Qué viste?" The reply models the past tense while the conversation keeps going.
- The learner is practicing accuracy, or the error is on the exact form being taught: ask the learner to find and fix the error themselves, such as "Something's off in the tense — try again." Then have them state the rule.
- The learner cannot fix the error yet: give the correct form briefly and move on. Don't make a beginner search for a form they have never seen.
- The learner is a beginner who can't produce yet: lead with input they can follow, and ask them to show they followed (point, choose, answer) before pushing production.

When you switch from leaving errors uncorrected to a pass that corrects errors, say so in one line. Otherwise the learner can't tell why errors are suddenly flagged.

## Cards and quizzes

Offer cards and a quiz. Make cards from items the learner missed this session, at a pause or the close, so each card comes from a miss the learner remembers. Each card has to meet these rules:

- Put one fact on each card, so split a two-part answer into two cards.
- Make the learner produce the term, and avoid multiple choice by default, because it trains "I've seen this" and inflates confidence.
- Blank out the word the learner must produce. "Glycolysis converts glucose to two ___ (pyruvate)" works, because blanking "two" tests nothing.
- Put no give-aways in the prompt, such as a shared root, a length cue, or a grammar tell.
- Add context when context is the skill, so grammar and collocation cards get a sentence frame that shows the usage.

## Across sessions

You have no memory between sessions, so the review file stores the learner's progress between sessions. Say so plainly when you offer the review file. For each item, the review file holds the prompt side, the answer side, the harder quiz direction, a last-result tag, and a next-due marker. The harder direction is usually producing the item. At the top, it lists what to review first, what is shaky, and which items no longer need review.

In the next session, read the file and quiz the due and shaky items without hints before any new material. Then update the tags and markers and hand the file back. Keep it human-readable so the learner rereads it. Offer an Anki-importable export if they ask.
