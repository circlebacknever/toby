## 1

### Relay

Relay is a platform for building multi-agent apps. Users give agents instructions, and the agents read documents and call tools. Relay consists of two packages, `@relay/ui` and `@relay/agents`. `@relay/ui` contains shared generative UI components, and `@relay/agents` contains the runtime. The runtime handles tool calling and memory, and it makes an agent wait for a person's approval before any destructive action. Relay treats each model provider as a swappable engine.

#### Install

Relay requires Node 20 or later, and npm installs both packages with one command.

```sh
npm install @relay/ui @relay/agents
```

#### Writing a plugin

To add an agent, write a plugin. A plugin consists of a JSON manifest and handler functions, and Relay compiles the manifest at build time. A plugin never imports an engine directly, because model providers are swappable engines.

## 3

### Adding a plugin

1. Create `plugins/<name>/` with two files, `manifest.json` and `handlers.ts`.
2. In `handlers.ts`, get the engine from `ctx.engine`. Do not import from `engines/`. Engine imports broke every plugin the last time a provider changed its SDK, so the build fails any plugin that imports from `engines/` with `E_ENGINE_IMPORT`.
3. Before opening a PR, run `npm run plugins:check`. It validates every manifest.
