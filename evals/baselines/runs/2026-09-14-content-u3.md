## 1

# Relay

Relay is a platform for building multi-agent apps. Users give agents instructions, and agents read documents, call tools, and wait for a person to approve anything destructive. Relay consists of two packages. `@relay/ui` contains shared generative UI components, and `@relay/agents` contains the runtime for tool calling, memory, and pauses for approval. Model providers are swappable engines in Relay.

### Install

Install both packages with this command, which needs Node 20 or later.

```sh
npm install @relay/ui @relay/agents
```

### Writing a plugin

Each new agent is a plugin, which consists of a JSON manifest and a set of handler functions. Relay compiles the manifest at build time.

## 3

### Adding a plugin

Each plugin is a directory, `plugins/<name>/`, that contains `manifest.json` and `handlers.ts`.

1. Create `plugins/<name>/` with a `manifest.json` file and a `handlers.ts` file.
2. In `handlers.ts`, get the engine from `ctx.engine`, which every handler receives.
3. Do not import from `engines/` anywhere in the plugin. The build fails a plugin that imports from `engines/` with `E_ENGINE_IMPORT`.
4. Run `npm run plugins:check` before you open a PR. The command validates every manifest.

The build rejects engine imports because those imports broke every plugin the last time a provider changed its SDK.
