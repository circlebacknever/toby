## 1

### Relay

Relay is a platform for building multi-agent apps. Users give agents instructions, and the agents read documents and call tools. Relay ships two packages, `@relay/ui` for shared generative UI components and `@relay/agents` for the runtime. The runtime handles tool calling, memory, and pauses for human approval before a destructive action. Model providers are swappable in Relay.

#### Install

Relay requires Node 20 or later, and one command installs both packages.

```sh
npm install @relay/ui @relay/agents
```

#### Writing a plugin

You add a new agent to Relay by writing a plugin. A plugin consists of a JSON manifest and a set of handler functions, and Relay compiles the manifest at build time.

## 3

### Adding a plugin

Each plugin is a directory, `plugins/<name>/`, that contains `manifest.json` and `handlers.ts`.

1. Create `plugins/<name>/` and add `manifest.json` and `handlers.ts` to it.
2. In `handlers.ts`, get the engine from `ctx.engine`. Do not import from `engines/` in any plugin file, because the build fails that plugin with `E_ENGINE_IMPORT`. Engine imports broke every plugin the last time a provider changed its SDK, which is why the build rejects them.
3. Before you open a PR, run `npm run plugins:check`. It validates every manifest.

`api/webhooks.ts:41`

**Consequence:** A payment event that `processEvent` fails to handle never gets processed. The handler logs the error and returns 200, and the payment provider stops retrying a webhook once it gets a 200. The log line records `err` and leaves out `req.body`, so the event itself is not saved anywhere for a retry.

**Fires when:** `processEvent(req.body)` throws on any webhook delivery from the payment provider.

**Guard:** The `catch` block only calls `logger.warn(err)`, and then `res.status(200).send()` runs whether or not processing succeeded. I read only this hunk and did not run the handler, so a replay job elsewhere in the repo is unchecked.

Send a 500 from the `catch` block so the provider retries the delivery, and keep the 200 for the success path.
