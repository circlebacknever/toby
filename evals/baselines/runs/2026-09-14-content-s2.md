## 1

### Relay

Relay is a platform for building multi-agent apps, and it consists of two packages. `@relay/ui` contains shared generative UI components, and `@relay/agents` contains the runtime for tool calling and memory. Users give each agent instructions, and the agent reads documents and calls tools to follow them. Before an agent takes a destructive action, it waits for a person to approve that action.

#### Install

Relay needs Node 20 or later. Run this command to install both packages.

```sh
npm install @relay/ui @relay/agents
```

#### Writing a plugin

You add a new agent to Relay by writing a plugin. A plugin consists of a JSON manifest and handler functions, and Relay compiles the manifest at build time. Each model provider runs as a swappable engine. Plugins never import an engine directly, so you can swap the model provider without changing plugin code.

## 3

### Adding a plugin

Each plugin lives in `plugins/<name>/` and contains two files, `manifest.json` and `handlers.ts`. Follow these steps to add a plugin.

1. Create `plugins/<name>/manifest.json` and `plugins/<name>/handlers.ts`.
2. Get the engine from `ctx.engine` inside each handler that needs it.
3. Run `npm run plugins:check` before you open a PR. The check validates every manifest.

Do not import from `engines/` in a plugin. The build fails any plugin that imports from `engines/` with `E_ENGINE_IMPORT`. The build enforces this rule because engine imports broke every plugin the last time a provider changed its SDK.
