## 1

### Relay

Relay is a platform for building multi-agent apps. You give each agent instructions, and the agent reads documents and calls tools. Before a destructive action runs, the agent waits for a person to approve it. The runtime for tool calling, memory, and approvals is in the `@relay/agents` package. The `@relay/ui` package contains the generative UI components that agents share.

#### Install

Relay needs Node 20 or later, and this npm command installs both packages:

```sh
npm install @relay/ui @relay/agents
```

#### Writing a plugin

Each new agent is a plugin, which consists of a JSON manifest and a set of handler functions. Relay compiles the manifest at build time. Model providers are swappable engines, so a plugin never imports an engine directly.

## 3

### Adding a plugin

Each plugin lives in its own directory, `plugins/<name>/`, with a `manifest.json` and a `handlers.ts`.

1. Create `plugins/<name>/` and add `manifest.json` and `handlers.ts` to it.
2. In each handler, get the engine from `ctx.engine`.
3. Do not import from `engines/` anywhere in the plugin. If a plugin imports from `engines/`, the build fails that plugin with `E_ENGINE_IMPORT`.
4. Run `npm run plugins:check` before you open a PR. The command validates every manifest.

The build enforces the `engines/` rule because engine imports broke every plugin the last time a provider changed its SDK.
