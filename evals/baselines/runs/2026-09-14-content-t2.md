## 1

### Relay

Relay is a platform for building multi-agent apps. It consists of two packages. `@relay/ui` contains the shared components for generative UI, and `@relay/agents` contains the runtime for tool calling, memory, and human approval. A user gives an agent instructions, and the agent reads documents and calls tools. Before any destructive action, the agent pauses and waits for a person to approve it.

### Install

Install both packages with `npm install @relay/ui @relay/agents`, which requires Node 20 or later.

### Writing a plugin

To add an agent, write a plugin. A plugin consists of a JSON manifest and handler functions, and Relay compiles the manifest at build time. Model providers run as engines that Relay can swap, so a plugin never imports an engine directly.

## 3

### Adding a plugin

Each plugin is a directory at `plugins/<name>/` that contains `manifest.json` and `handlers.ts`.

1. Create the directory and both files.
2. In each handler, get the engine from `ctx.engine`.
3. Do not import from `engines/` anywhere in the plugin. The build fails the plugin with `E_ENGINE_IMPORT`, because engine imports broke every plugin the last time a provider changed its SDK.
4. Run `npm run plugins:check` before you open a PR. The command validates every manifest.
