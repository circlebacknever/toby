## 1

### Relay

Relay is a platform for building multi-agent apps. Users give agents instructions, and agents read documents, call tools, and wait for a person to approve anything destructive. Relay ships as two packages. `@relay/ui` contains shared generative UI components, and `@relay/agents` contains the runtime that handles tool calling, memory, and the wait for approval.

#### Install

Relay requires Node 20 or later. Install both packages from npm with this command.

```sh
npm install @relay/ui @relay/agents
```

#### Writing a plugin

To add an agent to Relay, write a plugin. A plugin consists of a JSON manifest and a set of handler functions, and Relay compiles the manifest at build time. Model providers are swappable engines, and a plugin never imports an engine directly.

## 3

### Adding a plugin

Each plugin lives in its own directory and consists of two files.

1. Create `plugins/<name>/` with `manifest.json` and `handlers.ts`.
2. In a handler, get the engine from `ctx.engine`.
3. Before you open a PR, run `npm run plugins:check`. The command validates every manifest.

Do not import anything from `engines/` in a plugin. The build fails any plugin that does with `E_ENGINE_IMPORT`. The rule exists because engine imports broke every plugin the last time a provider changed its SDK.
