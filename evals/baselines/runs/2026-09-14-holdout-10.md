## 1

### Ledgerline

Ledgerline is a command-line tool that reconciles bank CSV exports from Chase, Monzo, Wise, and ING against an accounting system. It matches a bank row to a ledger entry when the amounts are equal and the dates are within 2 days of each other. Rows that Ledgerline cannot match go to `review.csv` for a person to check. Ledgerline reads the accounting system through an API token with read-only scope.

#### Install

Ledgerline needs Python 3.11 or later. When that version is installed, run `brew install ledgerline`.

#### Add a bank format

To add a bank format, write a parser in `parsers/<bank>.py`. Parsers must not make network calls, and CI fails any parser that imports `requests` or `httpx`.

## 3

### Options considered

Sessions are in a single Redis node that is at 71 percent of its memory and grows about 3 percentage points a week. At that rate, the node reaches 100 percent in about 10 weeks. The session read runs once per page load, so its latency adds to every page load under either option.

#### Option A: shard sessions across two Redis nodes

Option A adds a second Redis node and shards sessions across both nodes. Session reads stay on Redis, where they took 2 ms at p95 in staging. The team has not run sharded Redis before.

#### Option B: move sessions to Postgres

Option B moves sessions to the existing Postgres cluster, which has 40 percent headroom. In staging, session reads took 9 ms at p95 on Postgres and 2 ms on Redis.
