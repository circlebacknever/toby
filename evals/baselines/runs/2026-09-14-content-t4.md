## 1

### Relay

Relay is a platform for building multi-agent apps. In a Relay app, users give agents instructions, and the agents read documents, call tools, and wait for a person to approve anything destructive. Relay ships as two packages, `@relay/ui` for shared generative UI components and `@relay/agents` for the runtime. The runtime handles tool calling, memory, and the wait for a person's approval.

#### Install

Relay requires Node 20 or later, and you install both packages from npm.

```sh
npm install @relay/ui @relay/agents
```

#### Writing a plugin

You add a new agent to Relay by writing a plugin. A plugin consists of a JSON manifest and handler functions, and Relay compiles the manifest at build time. Model providers are swappable engines, so a plugin never imports an engine directly.

## 3

### Adding a plugin

Each plugin is a directory at `plugins/<name>/` that contains `manifest.json` and `handlers.ts`.

1. Create `plugins/<name>/` and add both files to it.
2. In `handlers.ts`, get the engine from `ctx.engine`, which every handler receives.
3. Do not import anything from `engines/`. The build fails any plugin that does with `E_ENGINE_IMPORT`. This rule exists because engine imports broke every plugin the last time a provider changed its SDK.
4. Run `npm run plugins:check` before you open a PR. The command validates every manifest.
