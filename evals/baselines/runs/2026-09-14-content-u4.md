## 1

### Relay

Relay is a platform for building multi-agent apps. Users give agents instructions, and the agents read documents, call tools, and wait for a person to approve anything destructive. The `@relay/agents` package contains the runtime for tool calling, memory, and the approval pauses, and `@relay/ui` contains shared generative UI components. Model providers are swappable in Relay.

#### Install

Relay requires Node 20 or later, and this command installs both packages.

```sh
npm install @relay/ui @relay/agents
```

#### Writing a plugin

You add a new agent to Relay by writing a plugin. A plugin consists of a JSON manifest and handler functions, and Relay compiles the manifest at build time.

## 3

### Adding a plugin

Each plugin is a directory at `plugins/<name>/` that contains `manifest.json` and `handlers.ts`.

1. Create `plugins/<name>/` and add `manifest.json` and `handlers.ts` to it.
2. In a handler, get the engine from `ctx.engine`.
3. Do not import from `engines/` anywhere in the plugin. The build fails a plugin that does with `E_ENGINE_IMPORT`.
4. Run `npm run plugins:check` before you open a PR. The command validates every manifest.

The build rejects engine imports because they broke every plugin the last time a provider changed its SDK.
