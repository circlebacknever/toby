## 1

### Relay

Relay is a platform for building multi-agent apps. Users give agents instructions, and the agents read documents, call tools, and wait for a person to approve anything destructive. Relay ships two packages, `@relay/ui` for shared generative UI components and `@relay/agents` for the runtime. The runtime handles tool calling, memory, and the pause for human approval before a destructive action. Model providers are engines, and an app can swap one engine for another.

### Install

Relay needs Node 20 or later. Install both packages from npm with this command.

```sh
npm install @relay/ui @relay/agents
```

### Writing a plugin

Each new agent is a plugin, which consists of a JSON manifest and a set of handler functions. Relay compiles the manifest at build time. A plugin never imports an engine directly, so swapping the engine leaves every plugin unchanged.

## 3

### Adding a plugin

Each plugin lives in `plugins/<name>/` and consists of `manifest.json` and `handlers.ts`. Follow these steps to add one.

1. Create `plugins/<name>/` with `manifest.json` and `handlers.ts` inside it.
2. In `handlers.ts`, get the engine from `ctx.engine`.
3. Run `npm run plugins:check` before you open a PR. The command validates every manifest.

Do not import from `engines/` anywhere in a plugin. The build fails a plugin that does with `E_ENGINE_IMPORT`. This rule exists because engine imports broke every plugin the last time a provider changed its SDK.
