## 1

### Ledgerline

Ledgerline is a command-line tool that reconciles bank CSV exports against an accounting system. It reads exports from Chase, Monzo, Wise, and ING. Ledgerline matches a bank row to a ledger entry when the amounts are equal and the dates are within 2 days of each other. It writes every row it cannot match to `review.csv` for a person to check. It reads the accounting system through an API token that has read-only scope.

#### Install

Ledgerline needs Python 3.11 or later. Install it with `brew install ledgerline`.

#### Adding a bank format

To add a bank format, write a parser at `parsers/<bank>.py`. A parser must not make network calls, and CI fails any parser that imports `requests` or `httpx`.

## 3

### Options considered

Sessions are stored in a single Redis node, whose memory use is at 71 percent and grows by about 3 percentage points a week. No option has been chosen yet.

#### Shard sessions across two Redis nodes (option A)

Option A adds a second Redis node and shards sessions across both nodes. The team has not run sharded Redis before.

#### Move sessions to Postgres (option B)

Option B moves sessions to the existing Postgres cluster, which has 40 percent headroom. In staging, session reads took 9 ms at p95 on Postgres and 2 ms on Redis. The session read runs once per page load, so the 7 ms difference at p95 applies to every page load.
