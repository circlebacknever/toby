## 1

### Relay

Relay is a platform for building multi-agent apps. Users give agents instructions, and the agents read documents, call tools, and wait for a person to approve anything destructive. The shared generative UI components are in the `@relay/ui` package, and the runtime is in the `@relay/agents` package. The runtime handles tool calling, memory, and the pause for approval before a destructive action. Each model provider runs as an engine, and an app can swap one engine for another.

### Install

Relay needs Node 20 or later. Run this command to install both packages.

```sh
npm install @relay/ui @relay/agents
```

### Writing a plugin

To add a new agent, write a plugin. The plugin consists of a JSON manifest and handler functions, and Relay compiles the manifest at build time.

## 3

### Adding a plugin

A plugin is a directory at `plugins/<name>/` that contains `manifest.json` and `handlers.ts`.

1. Create `plugins/<name>/` with `manifest.json` and `handlers.ts`.
2. In each handler, use the engine that the handler receives through `ctx.engine`.
3. Run `npm run plugins:check` before you open a PR. The command validates every manifest.

Do not import from `engines/` in a plugin, because the build fails that plugin with `E_ENGINE_IMPORT`. The build enforces this rule because engine imports broke every plugin the last time a provider changed its SDK.
