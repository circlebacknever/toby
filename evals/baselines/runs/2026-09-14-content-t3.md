## 1

### Relay

Relay is a platform for building multi-agent apps. A user gives agents instructions, and the agents read documents and call tools. The `@relay/ui` package contains shared generative UI components, and the `@relay/agents` package contains the runtime. The runtime handles tool calling, memory, and a pause for a person's approval before any destructive action.

#### Install

Relay requires Node 20 or later, so check `node --version` before you install both packages with this command.

```sh
npm install @relay/ui @relay/agents
```

#### Writing a plugin

To add an agent, write a plugin. A plugin consists of a JSON manifest and handler functions, and Relay compiles the manifest at build time. Model providers are swappable engines in Relay, so a plugin never imports an engine directly.

## 3

### Adding a plugin

Each plugin is a directory at `plugins/<name>/` that contains `manifest.json` and `handlers.ts`.

1. Create `plugins/<name>/`, and add `manifest.json` and `handlers.ts` to it.
2. In `handlers.ts`, get the engine from `ctx.engine`, which every handler receives.
3. Do not import from `engines/` in a plugin. The build fails any plugin that does with `E_ENGINE_IMPORT`. The build has this check because engine imports broke every plugin the last time a provider changed its SDK.
4. Before you open a PR, run `npm run plugins:check`. The command validates every manifest.
