## 1

### Relay

Relay is a platform for building multi-agent apps. Users give agents instructions, and the agents read documents, call tools, and wait for a person to approve anything destructive. The `@relay/ui` package contains shared generative UI components, and the `@relay/agents` package contains the runtime for tool calling, memory, and approval pauses. Relay also lets an app swap its model provider.

#### Install

Relay needs Node 20 or later, and npm installs both packages with one command.

```sh
npm install @relay/ui @relay/agents
```

#### Writing a plugin

You add a new agent to Relay by writing a plugin. A plugin consists of a JSON manifest and handler functions, and Relay compiles the manifest at build time.

## 3

### Adding a plugin

Each plugin is a directory, `plugins/<name>/`, that contains `manifest.json` and `handlers.ts`.

1. Create `plugins/<name>/`, and add `manifest.json` and `handlers.ts` to it.
2. In `handlers.ts`, get the engine from `ctx.engine`, which every handler receives. If a plugin imports from `engines/`, the build fails that plugin with `E_ENGINE_IMPORT`.
3. Run `npm run plugins:check` before you open a PR, because it validates every manifest.

The build rejects engine imports because they broke every plugin the last time a provider changed its SDK.
