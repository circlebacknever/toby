## 1

### Relay

Relay is a platform for building multi-agent apps. Users give agents instructions, and agents read documents, call tools, and wait for a person to approve anything destructive. Relay has two packages, and `@relay/ui` contains its shared generative UI components. The `@relay/agents` package contains the runtime, which handles tool calling, memory, and pauses for human approval before a destructive action.

### Install

Install both packages with npm on Node 20 or later.

```sh
npm install @relay/ui @relay/agents
```

### Writing a plugin

A developer adds a new agent to Relay by writing a plugin. Each plugin consists of a JSON manifest and a set of handler functions, and Relay compiles the manifest at build time. Relay treats model providers as swappable engines, and a plugin never imports an engine directly.

## 3

### Adding a plugin

Each plugin is a directory, `plugins/<name>/`, that contains two files, `manifest.json` and `handlers.ts`.

1. Create `plugins/<name>/` and add `manifest.json` and `handlers.ts` to it.
2. In `handlers.ts`, use the engine that each handler receives as `ctx.engine`.
3. Do not import anything from `engines/` in a plugin. The build fails any plugin that does with `E_ENGINE_IMPORT`. The build blocks these imports because they broke every plugin the last time a provider changed its SDK.
4. Run `npm run plugins:check` before you open a PR. The command validates every manifest.
